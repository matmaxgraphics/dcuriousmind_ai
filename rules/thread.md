# Thread Rules

1. Create 5–7 tweets. Fewer or more fails validation.
2. Each tweet must be 280 characters or fewer, including the source link.
3. Tweet 1 must stand on its own and create curiosity.
4. Prefer opening with a question when appropriate.
5. Do not reveal the answer immediately.
6. Each tweet should advance the explanation.
7. Do not simply split paragraphs into tweets.
8. Keep each tweet concise.
9. Avoid unnecessary jargon.
10. Do not use fake suspense.
11. Do not repeat the same information.
12. Preserve scientific uncertainty.
13. Do not introduce facts that are not present in the supplied material.
14. The final tweet should provide a satisfying conclusion.
15. The thread should feel like a human explaining something they genuinely
    found interesting.
